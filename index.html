ChatECL: AI Research Platform

AI Technical Lead · Halverson Lab, Wisconsin Center for Education Research (WISCURDS) · Feb 2026–present

Document processingRAGEvaluation & user testingCloud

ChatECL helps education researchers analyze interviews: transcribing them, organizing them, and asking questions about them. I own the platform, work directly with researchers to adapt it to their needs, and ship features like transcript editing and speaker labeling through CI/CD.

40 → 2–3 mintranscription per interview
~600documents structured into PostgreSQL
90%+faster turnaround

How it works

Interview audio & documents→Gemini transcription→PostgreSQL data model→RAG (Pinecone) + read-only SQL tool→AI assistant for researchers

What I built

  • Turned ~600 messy interview documents into a structured PostgreSQL data model with Python, SQL, and LLMs.
  • Built a read-only SQL tool so the AI assistant can query live data without being able to change it.
  • Help maintain the platform's retrieval-augmented generation (RAG) pipeline with Pinecone vector search.
  • Built an evaluation setup for the beta transcription page: click-through tracking, screen-recording review, and an automated pipeline that gathers feature ratings into a Google Form.
  • Leading a new district-comparison dashboard (in progress) on a staged Google Cloud pipeline: Cloud Storage → VM → clean table → separate Cloud SQL database.

Key decisions

Test with real users before switching.I compared competing transcription models on output quality, then released a beta version of the new transcription page before rolling it out. To evaluate it, I tracked click-through rates, watched screen recordings of researchers using the page, and built an automated pipeline that collects how users rate each feature into a Google Form. That way the speedup didn't cost accuracy, and we knew which features researchers actually used.
Read-only by design.The AI assistant can look at research data but can never edit or delete it.
Keep new work away from production.The dashboard pipeline is separate from the live platform, raw files are never overwritten, and teammates get least-privilege, upload-only access with privacy checks.
Don't pay before you know.I built a cost model from billing data, checked vendor rates against invoices, and held off on ~$30/month in database spend until we knew how much data we'd have.

CareCompass: AI Medical Triage Assistant

ClaudeHacks (Anthropic-sponsored) · Honorable Mention · Nov 2025

Vector searchHealthcareTeam project

Many students freeze or panic when they feel sick because they don't know whether they need urgent care, a clinic, or just rest. CareCompass lets a student describe their symptoms in plain language and points them to the right level of care.

60 minto build
<100 msto return an urgency score
384-dimsentence embeddings

How it works

  • Symptom descriptions are embedded with sentence-transformers and matched against 26 care scenarios in a FAISS index.
  • The tool returns an urgency score and nearby UW Health facilities.
  • Flask backend with a simple React interface, so a stressed student only has to describe how they feel.

My part

  • Urgency score: developed the feature that turns a student's symptom match into an urgency score that points them to the right level of care.
  • Interface: designed the Flask and React interface students use to describe their symptoms and see results.
  • Built both with Claude Sonnet, Anthropic's latest model at the time, to move fast within the 60-minute limit.
Ship the simple version first.With 60 minutes, we chose fast similarity search over a trained model, so the tool worked end to end and could improve later.

Python · sentence-transformers · FAISS · Flask · React

UrbanPlot: Business Viability Prediction

MadData Hackathon (24 hours) · Feb 2026

NLPPredictive modelingTeam project

Madison has hundreds of vacant commercial lots. UrbanPlot scores each one on how likely a new business would be to succeed there, using what people are actually saying online as a signal of demand.

676vacant lots scored
7,466web-scraped posts analyzed
  • Applied RoBERTa sentiment analysis and BART zero-shot classification to scraped posts.

My part
